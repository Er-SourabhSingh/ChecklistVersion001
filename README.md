# 🚀 Selenium Automation - Checklist Plugin

## 🔧 Tech Stack
- Java  
- Selenium WebDriver  
- TestNG  
- Maven  
- Page Object Model (POM)  
- Data Driven Testing (Excel)  

---

## 📌 Features
- Automation of Checklist Plugin functionalities  
- Validation of checklist and sub-checklist workflows  
- Permission-based access testing  
- Checklist template creation and usage  
- Data-driven testing using Excel  
- Reusable and maintainable Hybrid Framework design  
- Test execution using TestNG  
- Generates detailed reports using Extent Reports  

---

## ▶️ How to Run
1. Clone the repository  
2. Import as a Maven project in IntelliJ IDEA  
3. Update test data in Excel file (if required)  
4. Run `testng.xml`  
5. View execution reports inside the `/reports` folder  

---

## 📂 Project Structure
- pageObjects/  
- testClasses/  
- utilities/  
- testData/  
- reports/  
- logs/  

---

## 🧪 Scenarios Covered
- Checklist creation, update, and deletion  
- Sub-checklist validation  
- Checklist behavior after issue closure  
- Progress bar validation on checklist selection/unselection  
- Permission-based checklist operations  
- Checklist template creation and usage
